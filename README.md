# Overview

NexusURL is a modern URL shortener and analytics platform built using Spring Boot and MongoDB. It provides fast URL shortening, QR code generation, click tracking, and real-time monitoring through Prometheus and Grafana, wrapped in a futuristic cyberpunk-inspired UI.

---

# Main Features

* ✨ Cyberpunk-inspired responsive UI
* 🚀 Instant URL shortening and fast redirection
* 📊 Click analytics and engagement tracking
* 🔗 QR code generation and download support
* 📱 Mobile-friendly responsive design
* ⚡ Real-time monitoring and performance tracking
* 📈 Prometheus metrics integration
* 🖥️ Grafana dashboard visualization

---

# Home Page & QR Code Generation

The home page allows users to:

* Enter long URLs
* Generate shortened URLs instantly
* Create downloadable QR codes
* Access analytics dashboard
* Copy shortened links easily

The UI is designed with a futuristic cyberpunk theme using neon colors and responsive layouts.

---

# Analytics Dashboard

The analytics dashboard displays:

* Original and shortened URL details
* Click tracking information
* Engagement metrics
* URL creation and expiration details
* Performance statistics

This helps monitor user interaction and link performance efficiently.

---

# Prometheus Monitoring

Prometheus is integrated to:

* Collect real-time application metrics
* Monitor server performance
* Track CPU, RAM, and network usage
* Store time-series monitoring data

It provides backend observability and monitoring support.

---

# Grafana Dashboard

Grafana dashboards visualize:

* CPU usage
* Memory utilization
* Disk usage
* Network traffic
* Application uptime
* System performance metrics

This enables real-time infrastructure monitoring and analytics visualization.
