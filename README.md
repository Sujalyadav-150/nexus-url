# Overview

NexusURL is a modern URL shortener and analytics platform built using Spring Boot and MongoDB. It provides fast URL shortening, QR code generation, click tracking, and real-time monitoring through Prometheus and Grafana, wrapped in a futuristic cyberpunk-inspired UI.

---

# Main Features

* ✨ Cyberpunk-inspired responsive UI
* 🚀 Instant URL shortening and fast redirection
* 📊 Click analytics and engagement tracking
* 🔗 QR code generation and download support
* 📱 Mobile-friendly responsive design
* ⚡ Real-time monitoring and performance tracking
* 📈 Prometheus metrics integration
* 🖥️ Grafana dashboard visualization

# Installation

```bash
git clone https://github.com/sujal/nexusurl.git
cd nexusurl
mvn spring-boot:run
```

---

# Configuration

```env
MONGO_URI=your_mongodb_connection_string
SERVER_PORT=8080
```
